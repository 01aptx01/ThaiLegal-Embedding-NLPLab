# การค้นมาตรา

เมื่อได้รับคำถาม ระบบแปลงคำถามและตัวบทเป็นเวกเตอร์ ซึ่งเป็นชุดตัวเลขที่ใช้เปรียบเทียบข้อความ แล้วจัดอันดับมาตราตามความคล้าย แต่ละวิธีใช้ตัวบทชุดเดียวกันและให้หนึ่งมาตราเป็นหนึ่งรายการ ค่าที่ต่างกันคือวิธีแปลงข้อความเป็นตัวเลข

## วิธีค้นทั้งสี่แบบ

| วิธี | ตัวเลขมาจากอะไร | ตัวอย่างการตีความ |
| --- | --- | --- |
| R1 · Binary Bag of Words | แต่ละช่องบอกว่าพบคำหนึ่งในข้อความหรือไม่ คำที่ซ้ำยังมีค่า 1 | ถ้าคำถามและมาตรามีคำว่า “ผู้เยาว์” เหมือนกัน คำนั้นช่วยให้ใกล้กัน การกล่าวซ้ำไม่เพิ่มค่า |
| R2 · TF-IDF | ให้น้ำหนักตามความถี่ของคำในข้อความและความหายากในคลัง | คำเฉพาะที่พบในมาตราไม่กี่แห่งมีน้ำหนักมากกว่าคำทั่วไปที่เจอแทบทุกมาตรา |
| R3 · Word2Vec Skip-gram | ฝึกเวกเตอร์คำจากตัวบท แล้วเฉลี่ยเวกเตอร์ของคำที่รู้จักในแต่ละข้อความ | คำที่มักอยู่ในบริบทคล้ายกันอาจให้ผลใกล้กัน แม้คำถามจะใช้คำคนละคำ |
| R4 · BGE-M3 | ใช้ [BAAI/bge-m3](https://huggingface.co/BAAI/bge-m3) แปลงข้อความทั้งช่วงเป็นเวกเตอร์ | คำถามที่เรียบเรียงใหม่อาจใกล้กับมาตราที่มีใจความคล้ายกัน ผลจริงต้องดูจากคะแนนในชุดทดสอบ |

R1–R3 ใช้ PyThaiNLP ตัวตัดคำ `newmm` ชุดเดียวกัน ส่วน BGE-M3 ใช้ตัวแบ่งข้อความของโมเดลเอง Word2Vec ฝึกจากคลังที่ใช้ค้น ตั้งค่า 150 มิติ หน้าต่าง 5 คำ ใช้คำที่พบอย่างน้อย 2 ครั้ง และฝึก 10 รอบด้วย worker เดียว

## จากเวกเตอร์ไปเป็นอันดับ

1. แปลงข้อความคำถามด้วยวิธีเดียวกับตัวบท และปรับความยาวเวกเตอร์ก่อนคำนวณ
2. คำนวณ cosine similarity กับตัวบททุกมาตรา แล้วเรียงจากค่ามากไปน้อย
3. ถ้าคะแนนเท่ากัน ให้มาตราที่มาก่อนในคลังอยู่ก่อน คำถามที่ได้เวกเตอร์ศูนย์จะคืนรายการว่าง
4. เก็บสูงสุด 10 มาตราสำหรับดูอันดับและวัดผล เมื่อสร้างคำตอบจะพิจารณาหลักฐานจาก 5 อันดับแรก

ตัวเลขความคล้ายใช้จัดอันดับภายในวิธีนั้น คะแนน 0.7 ของ TF-IDF และ 0.7 ของ BGE-M3 อาจมีความหมายต่างกัน ให้เทียบจากอันดับและคะแนนบนชุดคำถามเดียวกันแทน สำหรับ BGE-M3 แต่ละมาตรามีเพดาน 4,096 tokens ข้อความส่วนที่ยาวเกินอาจถูกตัดตอนสร้างเวกเตอร์ ดูรายการที่เกินได้ใน `corpus_lengths.csv` ของการทดลอง

## ดัชนีที่หน้าเว็บเปิดใช้

`thai-legal-rag-web build-index` สร้างเวกเตอร์ของตัวบทไว้ก่อน เมื่อเปิด `serve` เซิร์ฟเวอร์โหลดดัชนีและเตรียมตัวตัดคำไว้รอ คำถามใหม่จึงต้องแปลงเฉพาะข้อความคำถามแล้วนำไปเทียบกับข้อมูลที่เตรียมไว้ คำสั่งทดลอง `thai-legal-rag run` สร้างเวกเตอร์ขึ้นใหม่เพื่อวัดเวลาในแต่ละรอบ

| ไฟล์ในดัชนี | เก็บอะไร |
| --- | --- |
| `manifest.json` | รุ่นคลัง วิธีที่เปิดใช้ ลำดับรหัส และรุ่น BGE-M3 หากเปิด |
| `corpus.json` | ชื่อกฎหมาย เลขมาตรา และตัวบทเดิมสำหรับแสดงหลักฐาน |
| `r1_matrix.npz`, `r2_matrix.npz` | เวกเตอร์ของตัวบทสำหรับ Binary BoW และ TF-IDF |
| `r3_matrix.npy`, `r4_matrix.npy` | เวกเตอร์ของ Word2Vec และ BGE-M3 โดยไฟล์ R4 มีเมื่อสร้างดัชนีแบบครบ |
| `*.joblib` | ตัวแปลงคำถามหรือโมเดลที่ใช้ตอนค้น ให้เปิดจากดัชนีที่สร้างเองหรือมาจากแหล่งที่ไว้ใจได้ |

ถ้าสร้างดัชนี BGE-M3 ด้วย `--device cuda` ให้เปิดดัชนีด้วย `--device cuda` ด้วย เพราะระบบตรวจว่าชนิดตัวเลขที่ใช้แปลงคำถามตรงกับตอนสร้างดัชนี ดัชนี CPU ใช้ float32 ส่วน CUDA ใช้ float16 ตอนรันโมเดล

โค้ดจัดอันดับอยู่ใน [retrieval.py](../src/thai_legal_rag/retrieval.py) ส่วนการอ่านและเขียนดัชนีอยู่ใน [inference_index.py](../src/thai_legal_rag/inference_index.py)
