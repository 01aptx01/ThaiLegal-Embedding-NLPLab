# การสร้างคำตอบ

หลังค้นมาตรา ระบบใช้ [Typhoon 2 1B Instruct](https://huggingface.co/typhoon-ai/llama3.2-typhoon2-1b-instruct) ตอบเป็นภาษาไทย โมเดลรับคำถาม ตัวบท และคำสั่งให้ตอบจากตัวบทที่ให้มา ทุกวิธีค้นใช้คำสั่งและรุ่นโมเดลเดียวกันภายในรอบทดลอง เพื่อให้ดูได้ว่าการเปลี่ยนมาตราที่ค้นเจอมีผลต่อคำตอบอย่างไร

## จัดตัวบทที่จะส่งให้โมเดล

1. เลือกมาตราที่ค้นได้สูงสุด 5 อันดับแรก
2. ประกอบคำสั่ง คำถาม และตัวบทเดิม โดยใส่รหัสไว้หน้ามาตรา เช่น `[S00042]`
3. ลองเพิ่มมาตราทีละรายการตามอันดับ หากเพิ่มแล้วเกิน 4,096 tokens ให้ข้ามทั้งมาตรานั้นและลองมาตราถัดไป ข้อความในมาตราที่ส่งเข้าไปจะอยู่ครบ
4. ให้โมเดลตอบแบบเลือก token ที่มีคะแนนสูงสุดในแต่ละขั้น จำกัดคำตอบไว้ที่ 256 tokens โดยค่าเริ่มต้น

`token` คือหน่วยข้อความที่โมเดลอ่าน จำนวน token จึงอาจต่างจากจำนวนคำหรือจำนวนตัวอักษร เพดาน 4,096 นับคำสั่ง คำถาม ตัวบท และรูปแบบข้อความของโมเดลรวมกัน ส่วนเพดาน 256 ใช้กับข้อความคำตอบ

ตัวอย่าง ถ้า 5 อันดับแรกเป็น A, B, C, D, E และ B ยาวเกินงบหลังใส่ A ระบบจะลอง C ต่อทันที ดังนั้น “อยู่ในห้าอันดับแรก” กับ “ถูกส่งให้โมเดล” อาจได้คนละรายการ เปิดดูได้จาก `top_k_ids`, `prompt_ids` และ `omitted_ids`

ถ้าหลักฐานตอบไม่ได้ คำสั่งกำหนดให้ขึ้นต้นว่า “หลักฐานไม่เพียงพอ” บนเว็บ หากไม่มีมาตราใดส่งเข้าโมเดล ระบบจะส่งข้อความนี้ทันที

## ตรวจรหัสที่คำตอบอ้าง

ระบบตรวจรหัสรูปแบบ `[S00042]` แล้วเทียบกับรายการที่ส่งให้โมเดล ในเว็บ รหัสที่ตรวจพบว่าอยู่ในรายการนี้จะกดไปยังตัวบทได้ รหัสที่ไม่มีในรายการจะอยู่ใน `invalid_ids` การตรวจนี้บอกได้ว่าโมเดลได้รับตัวบทที่อ้างจริง ส่วนการดูว่าตัวบทสนับสนุนข้อความหรือไม่ต้องอ่านคำตอบเทียบหลักฐาน

| ตัวอย่าง | สิ่งที่อ่านได้ |
| --- | --- |
| รหัสอยู่ในคำตอบและอยู่ใน `prompt_ids` | โมเดลอ้างถึงตัวบทที่ได้รับ เปิดอ่านเพื่อตรวจใจความต่อได้ |
| รหัสอยู่ในคำตอบและอยู่ใน `invalid_ids` | รหัสนั้นไม่ได้อยู่ในชุดตัวบทที่ส่งให้โมเดล |
| มีมาตราอ้างอิงอยู่ใน `prompt_ids` แต่คำตอบยังผิด | กลับไปอ่านคำตอบกับตัวบทเพื่อตรวจว่าผิดที่ข้อสรุป เงื่อนไข หรือการอ้าง |

## คำตอบจากการทดลองกับคำตอบบนเว็บ

คำสั่งทดลองบันทึกคำตอบทั้งก้อนลง `generation_rows.jsonl` พร้อมคำตอบอ้างอิง เวลา และจำนวน token ส่วนเว็บทยอยส่งข้อความที่อ่านได้ออกมา แล้วส่งคำตอบฉบับเต็มในเหตุการณ์ `result` เมื่อโมเดลทำงานเสร็จ เวลา `ttft_ms` ที่หน้าเว็บแสดงวัดถึงข้อความชิ้นแรกที่ถอดรหัสได้จากจุดเริ่มสร้างคำตอบ ส่วน `generation_ms` วัดช่วงสร้างคำตอบ ค่าทั้งสองยังไม่รวมเวลาค้นคืนและเวลาเดินทางของข้อมูลถึงเบราว์เซอร์

การตั้งคำสั่ง การเลือกตัวบท และการเขียนผลทดลองอยู่ใน [generation.py](../src/thai_legal_rag/generation.py) การทยอยส่งข้อความอยู่ใน [inference_generation.py](../src/thai_legal_rag/inference_generation.py)
